# Kurd AI Academy Web App

This repository contains a responsive interactive learning web app for Kurd AI Academy.

## Included
- Modern landing page with multi-language support
- Kurdish, English, Arabic, and Turkish interface
- Course cards with learning paths
- Guided lesson content and quiz interactions
- Progress tracking stored in browser localStorage
- No backend required; runs as a static web application

## Run locally
Open `index.html` in a browser.

## Technology used
- HTML
- CSS
- JavaScript

## Notes
This is a front-end prototype for demonstration and learning purposes. It does not include authentication, a database, or a real admin panel yet.
